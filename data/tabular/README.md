# Tabular inputs

`patient_records.csv` is the original source dataset, moved without changing its Git blob. Its provenance is recorded in the source map. It is a learning dataset and is not evidence of a clinically validated predictor.

Add your external salary dataset as `salary_data.csv` with `YearsExperience` and `Salary` columns. Add Titanic training data as `titanic_train.csv`; the lesson expects the standard passenger columns, including `Survived`, `Name`, `Ticket`, `Embarked`, `Age`, `Cabin`, `Sex`, `Pclass`, `SibSp`, `Parch`, and `Fare`. These two datasets are not bundled.

The Adult Income project has its own `projects/adult_income/data/` directory and official UCI downloader.
